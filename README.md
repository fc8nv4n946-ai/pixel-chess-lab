# Pixel Chess Lab

Полноценные браузерные шахматы против локального **Stockfish 19 lite single-threaded**: React 19, TypeScript, Vite, chess.js. Авторские пиксельные фигуры, русский интерфейс и адаптивная доска. Никаких backend, API-ключей или внешних запросов во время игры.

## Запуск

Требуется Node.js 22.12+ (проверено с 24) и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite, с путём `/pixel-chess-lab/`. Файлы WASM должны обслуживаться HTTP-сервером: открытие `index.html` через `file://` не поддерживается.

```sh
npm run build
npm run preview
```

`dist/` содержит полностью автономный статический сайт: приложение, 12 SVG-спрайтов, движок, WASM, лицензии и соответствующие исходники Stockfish. Браузеру нужна поддержка WebAssembly; SharedArrayBuffer и специальные COOP/COEP-заголовки не требуются. Загрузка всех ресурсов происходит с того же сайта; это не PWA с гарантированным офлайн-кешем.

## Игра

Выберите сторону и один из пяти уровней. Нажмите фигуру, затем подсвеченную клетку; касания также поддерживаются. При превращении доступны ферзь, ладья, слон и конь. Рокировка выполняется ходом короля на две клетки.

Правила целиком обеспечивает chess.js: шах, мат, пат, рокировка, en passant, недостаточный материал, троекратное повторение и правило 50 ходов. Для MVP последние два условия автоматически завершают игру при распознавании chess.js, без отдельного заявления игрока. Часов и турнирных процедур FIDE нет.

- Подсвечиваются легальные ходы, последний ход и король под шахом.
- История использует стандартную SAN-нотацию; панель показывает фактически взятые фигуры.
- «Отменить ход» возвращает последнюю полную пару; во время расчёта отменяется только ещё не отвеченный ход игрока. В игре чёрными начальный ход CPU сохраняется при отмене следующей пары.
- «Новая партия» позволяет сменить цвет и уровень. «Перезапуск» повторяет настройки. Для перезапуска и сдачи есть подтверждение.
- Партия автоматически сохраняется в localStorage и восстанавливается после перезагрузки, включая результат сдачи. Новая игра заменяет сохранение. Если хранилище недоступно, показывается предупреждение.
- PGN скачивается отдельным файлом, включая расстановку FEN при нестандартной исходной позиции и итог партии. Импорта PGN в интерфейсе нет.
- Синтезированный звук можно отключить, предпочтение сохраняется локально.

### Сила соперника

| Уровень | Skill Level | Максимальная глубина | Лимит времени |
| ------- | ----------: | -------------------: | ------------: |
| Новичок |           0 |                    1 |         80 мс |
| Лёгкий  |           3 |                    4 |        200 мс |
| Средний |           8 |                    8 |        500 мс |
| Сложный |          15 |                   14 |       1100 мс |
| Мастер  |          20 |                   22 |       2200 мс |

Движок завершает поиск при достижении первого лимита. Это профили силы, а не обещанные рейтинги Elo: lite слабее полного Stockfish. Подтверждены реальные легальные ответы всех пяти профилей; статистическая калибровка рейтинга не проводилась. Движок работает в отдельном Web Worker. При отмене, перезапуске и новой партии worker уничтожается; устаревший результат не применяется. Каждый ответ повторно проверяет chess.js. При ошибке предлагается повторить расчёт.

## Проверки

```sh
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

Браузерные тесты запускают **production preview**, поэтому сначала нужна сборка. Если Chromium уже установлен, можно использовать `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`.

Vitest проверяет обе рокировки обоих цветов, запрет рокировки через шах, en passant и его отмену, четыре превращения, шах, мат, пат, ничьи, отмену за оба цвета, восстановление/повреждение сохранения и 12 уникальных спрайтов. Playwright запускает настоящий локальный WASM на каждом уровне; проверяет игровой цикл, сохранение, PGN, отмену, сдачу, перезапуск, превращение, восстановление мата, касания на мобильном экране, отсутствие горизонтального переполнения, отмену старого расчёта, отсутствие внешних запросов и ошибок консоли. Скриншоты сохраняются в `test-results/`.

Проверено в Chromium на Linux и мобильной эмуляции 390×844. Реальные iOS/Android и другие браузеры не проверялись.

## Структура

- `src/game/rules.ts` — правила, восстановление, результат и отмена пары ходов.
- `src/ai/engine.ts` — UCI, пять профилей поиска, загрузка и отмена worker.
- `src/game/sound.ts` — звук Web Audio.
- `src/game/useGame.ts` — состояние партии, жизненный цикл ИИ и сохранение.
- `src/App.tsx` — доска, стартовый экран и панели.
- `src/art/pieces.ts` — оригинальные пиксельные силуэты и палитры.
- `public/pieces/` — 12 отдельных SVG; `npm run art` воспроизводит их из исходников.
- `public/engine/` — локальный Stockfish.js/WASM, версия 19.0.1.
- `public/licenses/` — GPL, уведомления, лицензии зависимостей, исходники движка и NNUE.

Для будущих особых свойств предусмотрена граница `standardRules`: отдельный режим может использовать свой адаптер. Текущая игра всегда использует стандартные правила chess.js; модификаций правил нет.

## GitHub Pages

`vite.config.ts` задаёт `base: '/pixel-chess-lab/'`. Workflow `.github/workflows/pages.yml` при push в `main` выполняет установку из lockfile, unit-тесты, TypeScript, сборку и браузерные тесты, затем публикует `dist/` через GitHub Pages. Pull request только проверяется, без публикации.

Действия владельца репозитория:

1. Закоммитить и отправить подготовленные файлы в `main`, если они ещё не отправлены.
2. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**; разрешить Actions, если они отключены политиками репозитория.
3. Дождаться успешного workflow **Check and deploy to GitHub Pages**. При необходимости запустить его через **Run workflow**.

Ожидаемый адрес после успешной публикации: `https://fc8nv4n946-ai.github.io/pixel-chess-lab/`. Наличие файла workflow само по себе не означает, что сайт опубликован.
